# Context Menu

Use Context Menu for quick actions on an item people work with directly, such as a file, a canvas object or a row. It shares Menu's look and parts. Treat it as a shortcut, because many people never think to right-click.

## Install

```bash
npx shadcn@4.18.0 add @siteplane/context-menu
```

Import it from `@/siteplane/components/context-menu`. The project needs Siteplane UI's one-time setup first: [installation](https://ui.siteplane.io/docs/installation/).

## When to pick it

- **vs [Menu](https://uiskillbook.com/skills/siteplane-menu):** Also offer a visible Menu button for the same actions so people who never right-click can still reach them.
- **vs [Dropdown Menu](https://uiskillbook.com/skills/siteplane-dropdown-menu):** Pick Dropdown Menu instead when the menu opens from a visible button rather than from the element itself.
- **vs [Command](https://uiskillbook.com/skills/siteplane-command):** Pick Command instead when people search a large set of actions by typing.

## Rules

- Never make the context menu the only path to an action; mirror it in a visible control.
- For items that navigate, use ContextMenuLinkItem: it outputs an actual anchor and dismisses the menu on activation.
- Do not wrap ContextMenuPopup in another portal; it already includes the portal and positioner.
- Group related items with ContextMenuGroup and ContextMenuGroupLabel, and move rare actions into a submenu.
- Remember checkbox and radio items hold menu state and do not submit with a form.
