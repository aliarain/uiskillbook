# Line Chart

Line Chart shows trends such as active users per month or orders per hour, with up to about five series. It supports date axes, several curve styles and a crosshair tooltip that works by keyboard.

## Install

```bash
npx shadcn@4.18.0 add @siteplane/line-chart
```

Import it from `@/siteplane/components/line-chart`. The project needs Siteplane UI's one-time setup first: [installation](https://ui.siteplane.io/docs/installation/).

## When to pick it

- **vs [Area Chart](https://uiskillbook.com/skills/siteplane-area-chart):** Pick Area Chart when the size of the measure or how parts stack into a total matters.
- **vs [Bar Chart](https://uiskillbook.com/skills/siteplane-bar-chart):** Pick Bar Chart when the categories have no natural order.
- **vs [Sparkline](https://uiskillbook.com/skills/siteplane-sparkline):** Pick Sparkline for a tiny axis-free trend beside a number.

## Rules

- Pass `data`, the `x` key, `series` and a required `label`.
- Use `Date` objects at midnight UTC for a time axis; text x values are treated as categories.
- Keep `curve="monotone"` unless you have a reason, since it never overshoots the data; use `step` for values that jump.
- Write values with `formatValue` and set `locale`; missing values break the line rather than dropping to zero.
- Use `height="fill"` with `minHeight` to fill a card's remaining height.
