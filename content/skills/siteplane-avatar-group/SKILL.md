# Avatar Group

Avatar Group shows that a set of people belongs to something, such as project members or reviewers, without listing each name. It handles the overlap, the separating ring and the overflow pill.

## Install

```bash
npx shadcn@4.18.0 add @siteplane/avatar-group
```

Import it from `@/siteplane/components/avatar-group`. The project needs Siteplane UI's one-time setup first: [installation](https://ui.siteplane.io/docs/installation/).

## When to pick it

- **vs [Avatar](https://uiskillbook.com/skills/siteplane-avatar):** Pick a single Avatar when only one person is involved.
- **vs [Resource List](https://uiskillbook.com/skills/siteplane-resource-list):** Pick Resource List when every person needs their name and details visible on screen.

## Rules

- Place `Avatar` children straight inside `AvatarGroup`, then end with an `AvatarGroupCount` for the hidden members.
- Set `size` (`sm`, `md`, `lg`, `xl`) on the group rather than on each avatar so the overlap and the count scale together.
- Set `count` to the number of avatars left out, and pair it with screen-reader-only text naming what is counted, for example "more members".
- Decide in your own code how many avatars to render; the group does not measure or trim its children.
- On a custom surface, check that the ring colour matches the background, since it follows the kit surface it sits on.
