# Area Chart

Area Chart shows volume over time, such as page views, and when stacked shows how sources add up to a total. It shares the line chart's axes, curves and keyboard tooltip.

## Install

```bash
npx shadcn@4.18.0 add @siteplane/area-chart
```

Import it from `@/siteplane/components/area-chart`. The project needs Siteplane UI's one-time setup first: [installation](https://ui.siteplane.io/docs/installation/).

## When to pick it

- **vs [Line Chart](https://uiskillbook.com/skills/siteplane-line-chart):** Pick Line Chart when multiple series do not add up to a total; overlapping fills would obscure one another.
- **vs [Bar Chart](https://uiskillbook.com/skills/siteplane-bar-chart):** Pick Bar Chart for a few discrete periods or unordered categories.
- **vs [Sparkline](https://uiskillbook.com/skills/siteplane-sparkline):** Pick Sparkline with the area variant for a small inline trend.

## Rules

- Pass `data`, the `x` key, `series` and a required `label`.
- Use `stacked` when series are parts of one total; the tooltip still shows each series' own value.
- Choose `fill="gradient"` or `fill="solid"`; both keep a line along the top.
- Prefer the default `monotone` curve for data that rests on zero so the fill never dips below it.
- Format values with `formatValue` and translate the screen-reader text with `labels`.
