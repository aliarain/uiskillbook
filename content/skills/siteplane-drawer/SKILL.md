# Drawer

Drawer suits touch-first panels from any edge, such as a mobile navigation menu, an action sheet or filters. Snap points let a bottom panel rest half open. It also ships menu parts for action lists inside the panel.

## Install

```bash
npx shadcn@4.18.0 add @siteplane/drawer
```

Import it from `@/siteplane/components/drawer`. The project needs Siteplane UI's one-time setup first: [installation](https://ui.siteplane.io/docs/installation/).

## When to pick it

- **vs [Sheet](https://uiskillbook.com/skills/siteplane-sheet):** Pick Sheet instead for an edge panel that should not respond to swipe gestures, such as a desktop form.
- **vs [Detail Drawer](https://uiskillbook.com/skills/siteplane-detail-drawer):** Pick Detail Drawer instead to show one record's details beside a list.
- **vs [Dialog](https://uiskillbook.com/skills/siteplane-dialog):** Pick Dialog instead for a centred task that does not belong to an edge.

## Rules

- Set position on the Drawer root; the popup, bar and swipe direction follow it.
- Keep a visible close action, such as showCloseButton on DrawerPopup, for people who don't swipe.
- DrawerMenu items do not close the drawer. Wrap them in DrawerClose when a choice should close it.
- Put long content in DrawerPanel. It scrolls while the header and footer stay fixed.
- Use snapPoints for a bottom drawer that should open at a compact height before expanding.
