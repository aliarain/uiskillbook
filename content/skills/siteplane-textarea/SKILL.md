# Textarea

Textarea takes descriptions, comments, bios and messages that may wrap or run to paragraphs. It sizes itself to the text, so you set limits in lines instead of a fixed height.

## Install

```bash
npx shadcn@4.18.0 add @siteplane/textarea
```

Import it from `@/siteplane/components/textarea`. The project needs Siteplane UI's one-time setup first: [installation](https://ui.siteplane.io/docs/installation/).

## When to pick it

- **vs [Input](https://uiskillbook.com/skills/siteplane-input):** Pick Input when the answer fits on one line.
- **vs [Input Group](https://uiskillbook.com/skills/siteplane-input-group):** Pick Input Group with InputGroupTextarea when the box needs a header, footer or corner action like a send button.
- **vs [Prompt Input](https://uiskillbook.com/skills/siteplane-prompt-input):** Pick Prompt Input for a chat or AI composer with attachments and submit behavior built in.

## Rules

- Set height with `minLines` and `maxLines`; native `rows` does not control it.
- Listen with native `onChange`; Textarea has no `onValueChange`.
- Enforce limits with `maxLength` and show the remaining count from a controlled `value`.
- Label it through Field and FieldLabel, and put errors on the Field with FieldError.
- Use `readOnly` for submitted but locked text and `disabled` only when it should not submit.
