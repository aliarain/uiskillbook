# Empty State

Empty State appears once loading finishes and a list, table or view has nothing to show. It covers first-run screens, searches with no matches and recoverable gaps. Your app decides which case applies and which action fits.

## Install

```bash
npx shadcn@4.18.0 add @siteplane/empty-state
```

Import it from `@/siteplane/components/empty-state`. The project needs Siteplane UI's one-time setup first: [installation](https://ui.siteplane.io/docs/installation/).

## When to pick it

- **vs [Skeleton](https://uiskillbook.com/skills/siteplane-skeleton):** Pick Skeleton or Spinner instead while the data is still loading.
- **vs [Alert](https://uiskillbook.com/skills/siteplane-alert):** Pick Alert instead when an error appears but the rest of the page still shows content.

## Rules

- Show it only after loading has settled, never as a loading placeholder.
- Set level on EmptyTitle when the title should be a real heading in the page outline.
- Put the next-step buttons in EmptyContent and make the primary action the obvious one.
- For no matching results, keep search and filter controls visible and offer a way to clear them.
- Use EmptyMedia variant="icon" for a compact icon, or the default variant for richer media such as avatars.
