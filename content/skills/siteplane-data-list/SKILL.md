# Data List

Data List shows the properties of a single thing, such as an account, an invoice or a deployment, as a description list. It suits detail panels, summary cards and side drawers.

## Install

```bash
npx shadcn@4.18.0 add @siteplane/data-list
```

Import it from `@/siteplane/components/data-list`. The project needs Siteplane UI's one-time setup first: [installation](https://ui.siteplane.io/docs/installation/).

## When to pick it

- **vs [Table](https://uiskillbook.com/skills/siteplane-table):** Pick Table when people compare, sort or select many records instead of reading one.
- **vs [Settings List](https://uiskillbook.com/skills/siteplane-settings-list):** Pick Settings List when each row holds a control that changes a value.
- **vs [Native Table](https://uiskillbook.com/skills/siteplane-native-table):** Pick Native Table when the data has several columns per row rather than one label and one value.

## Rules

- Compose `DataList` with one `DataListItem` per property, each holding a `DataListLabel` and a `DataListValue` so labels and values pair up for screen readers.
- Switch to `orientation="vertical"` in narrow columns or for long values.
- Set `--data-list-label-width` when several lists stack and their value columns should line up.
- Turn on `dividers` to separate rows with hairlines; inline parts such as Badge, Code or a link can sit in a value.
- Keep it read-only and stateless; it renders on the server and has no editing behaviour.
