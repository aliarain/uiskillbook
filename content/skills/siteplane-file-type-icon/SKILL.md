# File Type Icon

File Type Icon gives file lists, upload rows and attachment cards a quick visual cue for PDFs, spreadsheets, images, code and more. It reads only the file name, so it works before any upload has finished.

## Install

```bash
npx shadcn@4.18.0 add @siteplane/file-type-icon
```

Import it from `@/siteplane/components/file-type-icon`. The project needs Siteplane UI's one-time setup first: [installation](https://ui.siteplane.io/docs/installation/).

## When to pick it

- **vs [Attachment](https://uiskillbook.com/skills/siteplane-attachment):** Pick Attachment when the file needs a full card with its name, upload state and actions; it can hold this icon as its media.

## Rules

- Pass the file name as `name`, or set `extension` when the name has no suffix, such as a document title.
- Print the file name next to the icon. The icon is `aria-hidden` and gives assistive technology no text.
- Pick a `size` of 16, 20, 24, 32 or 40; below 32 px the extension label is too small to read, so lean on the visible name.
- Prefer a real thumbnail for images and videos when you have one, and keep this icon for rows without a preview.
- Size outside the presets with a `className` that sets height and width in the 34:40 proportion.
