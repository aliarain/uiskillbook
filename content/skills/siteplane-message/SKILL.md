# Message

Message arranges a single turn in a conversation, placing bubbles, attachments, traces and actions in the right order and on the right side. It draws no surface itself and keeps no state.

## Install

```bash
npx shadcn@4.18.0 add @siteplane/message
```

Import it from `@/siteplane/components/message`. The project needs Siteplane UI's one-time setup first: [installation](https://ui.siteplane.io/docs/installation/).

## When to pick it

- **vs [Bubble](https://uiskillbook.com/skills/siteplane-bubble):** Use Bubble inside a Message for the text surface itself.
- **vs [Marker](https://uiskillbook.com/skills/siteplane-marker):** Pick Marker for a line that is not a turn, such as a date or system note.
- **vs [Message Scroller](https://uiskillbook.com/skills/siteplane-message-scroller):** Wrap many Messages in a Message Scroller for the thread's scrolling and announcements.

## Rules

- Compose `Message` with `MessageContent`, and add `MessageHeader`, `MessageFooter` and `MessageAvatar` as needed.
- Set `align="end"` for the writer's own turns and give the Bubbles inside the same `align`.
- Back-to-back messages from the same sender belong in one `MessageGroup`; give the earlier ones an empty `MessageAvatar` to keep them aligned.
- Each footer icon action needs an `aria-label`. A footer with nothing in it takes up no space, so it is safe to render before any actions arrive.
- Show a failed reply as a destructive Bubble with a Try again button and no rating actions.
