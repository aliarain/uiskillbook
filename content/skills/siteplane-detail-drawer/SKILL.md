# Detail Drawer

Detail Drawer shows the details of an item people pick from a list or table, without leaving the page. It has a header for the record name, a scrolling body and a footer for actions. Wrap it in a form to make an edit panel.

## Install

```bash
npx shadcn@4.18.0 add @siteplane/detail-drawer
```

Import it from `@/siteplane/components/detail-drawer`. The project needs Siteplane UI's one-time setup first: [installation](https://ui.siteplane.io/docs/installation/).

## When to pick it

- **vs [Drawer](https://uiskillbook.com/skills/siteplane-drawer):** Compose Drawer yourself when the panel is not about a single record.
- **vs [Sheet](https://uiskillbook.com/skills/siteplane-sheet):** Pick Sheet instead for a standalone form at the edge that has no swipe behavior.
- **vs [Alert Dialog](https://uiskillbook.com/skills/siteplane-alert-dialog):** Pick Alert Dialog instead for a short confirmation.

## Rules

- Name the record in the header with a title and keep a visible close action.
- Put the content in DetailDrawerBody so long records and forms scroll between the header and footer.
- Wrap header, body and footer in a form when editing, so Save submits; close the drawer after the save succeeds.
- Leave position on DetailDrawerPopup unset so it follows the root and the swipe direction matches.
- Write DetailDrawerPopup in new code; DetailDrawerContent is the older name.
