# Timeline

Timeline presents activity feeds, deploy histories, audit logs and a day's appointments. Events animate in and out as the list changes, and a now marker can sit between past and upcoming items.

## Install

```bash
npx shadcn@4.18.0 add @siteplane/timeline
```

Import it from `@/siteplane/components/timeline`. The project needs Siteplane UI's one-time setup first: [installation](https://ui.siteplane.io/docs/installation/).

## When to pick it

- **vs [Stepper](https://uiskillbook.com/skills/siteplane-stepper):** Pick Stepper when the items are steps a person works through, not events that happened.
- **vs [Resource List](https://uiskillbook.com/skills/siteplane-resource-list):** Pick Resource List when order in time is not the point and each row is an entity.

## Rules

- Render each `TimelineItem` directly inside `Timeline`, not inside a fragment, with `TimelineTitle` and `TimelineDescription`.
- Set `tone` for status colour and keep the status in text as well.
- Pass an icon as `marker`, and add `markerLabel` only when the marker says something the text does not.
- Use `TimelineNow` between events to mark the present, passing `label` in the page language.
- Wrap timestamps in `time` elements with a machine-readable `dateTime`, and supply events already sorted.
