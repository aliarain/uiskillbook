# Settings List

Settings List builds preference and account pages where each row is one setting with a switch, select, input or action button. It wires the labels and descriptions to the control and handles the responsive stacking.

## Install

```bash
npx shadcn@4.18.0 add @siteplane/settings-list
```

Import it from `@/siteplane/components/settings-list`. The project needs Siteplane UI's one-time setup first: [installation](https://ui.siteplane.io/docs/installation/).

## When to pick it

- **vs [Data List](https://uiskillbook.com/skills/siteplane-data-list):** Pick Data List when the rows only show values and nothing is editable.
- **vs [Card](https://uiskillbook.com/skills/siteplane-card):** Pick a plain Card when the content is not a set of individual settings.

## Rules

- Give `SettingsList` a `title` (set `titleLevel` to fit the page outline) and give each `SettingsListItem` a `title`.
- Render the control in the `control` render prop and spread every prop it receives so the label and description stay linked.
- Buttons like Change or Manage should get `aria-describedby` and nothing more, so their visible text remains the accessible name.
- Keep values, saving and validation in your app state; the list only draws the layout.
- Use `layout="inline"` for small controls like switches and leave wide text controls on the default `responsive` layout.
