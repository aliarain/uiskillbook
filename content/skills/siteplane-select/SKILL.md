# Select

Select picks from a known, moderate list such as a region, role or team, where search adds nothing. It supports groups, icons, multiple selection and a ghost trigger for values inside rows.

## Install

```bash
npx shadcn@4.18.0 add @siteplane/select
```

Import it from `@/siteplane/components/select`. The project needs Siteplane UI's one-time setup first: [installation](https://ui.siteplane.io/docs/installation/).

## When to pick it

- **vs [Combobox](https://uiskillbook.com/skills/siteplane-combobox):** Pick Combobox when the list is long enough that people need to type to find an option.
- **vs [Autocomplete](https://uiskillbook.com/skills/siteplane-autocomplete):** Pick Autocomplete when the answer can be any text and the options are suggestions.
- **vs [Radio Group](https://uiskillbook.com/skills/siteplane-radio-group):** Pick Radio Group for a few options people should see side by side.
- **vs [Menu](https://uiskillbook.com/skills/siteplane-menu):** Pick Menu when the list holds actions instead of a value.

## Rules

- Pass `items` to Select so the trigger shows a stored ID's label before the popup opens.
- Set `size` and `variant` on `SelectTrigger`, not on the root.
- Use `SelectGroup`, `SelectGroupLabel` and `SelectSeparator` for sections, and `SelectLabel` or FieldLabel to name the control.
- Use `itemToStringValue` for object items so the form submits the right string.
- Set `name` and `required` and place it in a Field. Form then blocks an empty submit and FieldError explains why.
- Don't use the placeholder as the label.
