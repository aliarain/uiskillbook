# Select

Use Select for picking from a known, moderate list such as a region, role or team, where search would be overkill. It supports groups, icons, multiple selection and a ghost trigger for values inside rows.

## Install

```bash
npx shadcn@4.18.0 add @siteplane/select
```

Import it from `@/siteplane/components/select`. The project needs Siteplane UI's one-time setup first: [installation](https://ui.siteplane.io/docs/installation/).

## When to pick it

- **vs [Combobox](https://uiskillbook.com/skills/siteplane-combobox):** Pick Combobox instead when the list is long enough that people need to type to find an option.
- **vs [Autocomplete](https://uiskillbook.com/skills/siteplane-autocomplete):** Pick Autocomplete instead when the answer can be any text and the options are only suggestions.
- **vs [Radio Group](https://uiskillbook.com/skills/siteplane-radio-group):** Pick Radio Group instead for a few options that people should see side by side.
- **vs [Menu](https://uiskillbook.com/skills/siteplane-menu):** Pick Menu instead when the list contains actions, not a value.

## Rules

- Pass `items` to Select so a stored ID shows its label in the trigger before the popup opens.
- Set `size` and `variant` on `SelectTrigger`, not on the root.
- Use `SelectGroup`, `SelectGroupLabel` and `SelectSeparator` for sections, and `SelectLabel` or FieldLabel to name the control.
- Use `itemToStringValue` for object items so the form submits the right string.
- Set `name` and `required` and place it in a Field so Form blocks an empty submit and FieldError explains it.
- Never use the placeholder as the label.
