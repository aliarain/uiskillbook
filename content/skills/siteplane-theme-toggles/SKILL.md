# Theme Toggles

Theme Toggles give a header or settings row a single control for dark mode with a sun-to-moon animation. They report state only; your theme provider applies the change.

## Install

```bash
npx shadcn@4.18.0 add @siteplane/theme-toggles
```

Import it from `@/siteplane/components/theme-toggles`. The project needs Siteplane UI's one-time setup first: [installation](https://ui.siteplane.io/docs/installation/).

## When to pick it

- **vs [Toggle Group](https://uiskillbook.com/skills/siteplane-toggle-group):** Pick Toggle Group when people choose among light, dark and system.
- **vs [Switch](https://uiskillbook.com/skills/siteplane-switch):** Pick Switch for a labelled dark mode setting inside a settings form.

## Rules

- Drive `SunMoonMorphToggle` or `LayeredThemeToggle` so that `pressed` is true in dark mode, and change the theme from `onPressedChange`.
- Drive `pressed` from your resolved theme so the icon and the app never disagree, including portalled overlays.
- Keep the accessible name constant (default Dark mode) and let `aria-pressed` report the state.
- Size it with `size` or let it follow the provider.
