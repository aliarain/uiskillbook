# Resource List

Resource List shows projects, tasks, deployments or similar items as compact rows with a coloured marker and trailing metadata. It works as navigation when rows are links and animates rows as they are added or removed.

## Install

```bash
npx shadcn@4.18.0 add @siteplane/resource-list
```

Import it from `@/siteplane/components/resource-list`. The project needs Siteplane UI's one-time setup first: [installation](https://ui.siteplane.io/docs/installation/).

## When to pick it

- **vs [Table](https://uiskillbook.com/skills/siteplane-table):** Pick Table when people compare several columns or need sorting and multi-select.
- **vs [Data List](https://uiskillbook.com/skills/siteplane-data-list):** Pick Data List for the fields of one record rather than many records.
- **vs [Timeline](https://uiskillbook.com/skills/siteplane-timeline):** Pick Timeline when the rows are events in time order joined by a connector.

## Rules

- Set `interactive` on `ResourceListItem` and render an anchor to make rows links; mark the current one with `active`.
- Give every `ResourceListIndicator` a `label` (and an `icon` if useful) so status is not carried by colour alone.
- Render rows as direct children with stable keys so add, remove and reorder animations track the right row.
- Use `variant` (`soft` or `divided`), `density` and `flush` to match the surrounding card or filter bar.
- Reach for List Box instead when you need managed keyboard selection; `selected` here only changes appearance on static and link rows.
