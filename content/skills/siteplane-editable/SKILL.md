# Editable

Editable shows a value as plain text with a pencil beside it, and opens a field in the same spot to change it. Fit it to values people read often and rename now and then: a project title, a page name, a saved view in a list.

## Install

```bash
npx shadcn@4.18.0 add @siteplane/editable
```

Import it from `@/siteplane/components/editable`. The project needs Siteplane UI's one-time setup first: [installation](https://ui.siteplane.io/docs/installation/).

## When to pick it

- **vs [Input](https://uiskillbook.com/skills/siteplane-input):** Pick Input for a value people fill in or change every visit, such as a settings form with one Save button.
- **vs [Form](https://uiskillbook.com/skills/siteplane-form):** Pick Form with open fields when several values change together and save as one.
- **vs [Dialog](https://uiskillbook.com/skills/siteplane-dialog):** Pick Dialog when a rename needs more than the name, such as a description and a visibility setting.

## Rules

- Label it with a Field and FieldLabel, or give `EditableInput` an `aria-label`.
- Set a `placeholder` for the empty state. Give `labels.edit` the item's name, such as "Rename project", so screen readers can tell pencils apart.
- Save in `onValueCommit`. `onValueChange` also fires on every keystroke and on cancel.
- In a list, set `activationMode="none"` so only the pencil opens the field and each row takes one tab stop.
- When a value needs checking before it saves, wrap Editable in a Field and show the message with FieldError. A failing value keeps the field open.
- Use `EditableTextarea` for text with line breaks; Cmd or Ctrl+Enter saves it.
