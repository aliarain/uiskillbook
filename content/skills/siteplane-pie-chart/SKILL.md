# Pie Chart

Pie Chart suits storage usage, plan mix or traffic split, where there are only a few parts of one whole. The donut can show a total in its centre and an unfilled remainder share.

## Install

```bash
npx shadcn@4.18.0 add @siteplane/pie-chart
```

Import it from `@/siteplane/components/pie-chart`. The project needs Siteplane UI's one-time setup first: [installation](https://ui.siteplane.io/docs/installation/).

## When to pick it

- **vs [Bar Chart](https://uiskillbook.com/skills/siteplane-bar-chart):** Pick Bar Chart when there are more than five or six shares or values need precise comparison.
- **vs [Bar List](https://uiskillbook.com/skills/siteplane-bar-list):** Pick Bar List for a ranked breakdown that reads better as rows.

## Rules

- Pass `data` items with a stable `id`, a `label` and a `value`, plus a required chart `label`.
- Mark the unused remainder with `empty` so it takes the neutral colour.
- Show a total with `centerValue` and `centerLabel` (format with `centerFormat`), or pass short custom `center` content.
- Choose the data order: the chart draws slices in array order, starting at the top and going clockwise.
- Leave room around the chart when `popOut` is on, because the active share steps up to 10 px outside its box.
