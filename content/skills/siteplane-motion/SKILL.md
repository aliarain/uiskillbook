# Motion

Use Motion when the data changes and you want the interface to show that change smoothly: rows added or removed, chips reflowing, a panel swapping steps, or a total rolling to a new figure. It needs no animation code and turns instant under reduced motion.

## Install

```bash
npx shadcn@4.18.0 add @siteplane/motion
```

Import it from `@/siteplane/components/motion`. The project needs Siteplane UI's one-time setup first: [installation](https://ui.siteplane.io/docs/installation/).

## When to pick it

- **vs [Collapsible](https://uiskillbook.com/skills/siteplane-collapsible):** Skip Motion for components that already animate themselves, such as Collapsible, Dialog or Toast.
- **vs [Skeleton](https://uiskillbook.com/skills/siteplane-skeleton):** Pick Skeleton instead to fill space while data loads; Motion animates the change once it arrives.

## Rules

- Give every MotionItem a stable key from the data, never the array index.
- Set the space between items with gap on MotionList, not a CSS gap.
- Move focus to a neighbouring item before removing one, because a leaving item is inert.
- Use MotionReveal with open for one block, MotionSwap with a changing swapKey for replaced content, and MotionNumber for figures.
- Virtualize lists with hundreds of rows instead of wrapping each in a Motion element.
