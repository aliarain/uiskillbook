# Bar List

Bar List shows top pages, top countries or traffic sources as rows you can compare at a glance. It renders fully on the server and glides to new values when the period changes.

## Install

```bash
npx shadcn@4.18.0 add @siteplane/bar-list
```

Import it from `@/siteplane/components/bar-list`. The project needs Siteplane UI's one-time setup first: [installation](https://ui.siteplane.io/docs/installation/).

## When to pick it

- **vs [Bar Chart](https://uiskillbook.com/skills/siteplane-bar-chart):** Pick Bar Chart if any value may fall below zero or readers need an axis to compare against.
- **vs [Table](https://uiskillbook.com/skills/siteplane-table):** Pick Table when rows need several values or must be clickable.
- **vs [Resource List](https://uiskillbook.com/skills/siteplane-resource-list):** Pick Resource List when a row should open or select something.

## Rules

- Pass `data` sorted in the order you want ranked, each item with a unique `id`, a `label` and a `value`, and name the list with `label`.
- Add a `heading` with `label` and `value` to name the two columns.
- Format values with `formatValue` or set `locale`; use `description` for a quieter second line such as a path.
- Keep a custom `color` light, because labels are written on top of the bars.
- Rows are display-only: they do not respond to clicks, hover or focus, so do not wire actions to them.
