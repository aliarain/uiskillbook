# Preview Card

Use Preview Card on links to people, projects or documents so readers can peek before opening them. The preview is extra information only. The link must make sense without it.

## Install

```bash
npx shadcn@4.18.0 add @siteplane/preview-card
```

Import it from `@/siteplane/components/preview-card`. The project needs Siteplane UI's one-time setup first: [installation](https://ui.siteplane.io/docs/installation/).

## When to pick it

- **vs [Tooltip](https://uiskillbook.com/skills/siteplane-tooltip):** Pick Tooltip instead for a one-line label on a control.
- **vs [Popover](https://uiskillbook.com/skills/siteplane-popover):** Pick Popover instead when the content holds actions or fields people must reach by keyboard.

## Rules

- Keep the link text clear on its own; never hide required information in the card.
- Do not place required buttons or actions in the card.
- Tune delay and closeDelay on PreviewCardTrigger if the default timing feels slow or jumpy.
- Give PreviewCardPopup a width class when the content needs more than the default width.
