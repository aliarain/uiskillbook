# Tooltip

Tooltip names icon buttons or adds a brief, optional explanation to a control. It appears on hover and keyboard focus. Put essential information in the page as well.

## Install

```bash
npx shadcn@4.18.0 add @siteplane/tooltip
```

Import it from `@/siteplane/components/tooltip`. The project needs Siteplane UI's one-time setup first: [installation](https://ui.siteplane.io/docs/installation/).

## When to pick it

- **vs [Popover](https://uiskillbook.com/skills/siteplane-popover):** Pick Popover instead when the content is interactive or must open on tap.
- **vs [Preview Card](https://uiskillbook.com/skills/siteplane-preview-card):** Pick Preview Card instead for a richer preview of a link's destination.
- **vs [Truncate](https://uiskillbook.com/skills/siteplane-truncate):** Use Truncate for cut-off text; it adds the tooltip with the full text for you.

## Rules

- Mount TooltipProvider once near the app root, and group nearby tooltips under one provider so later ones open without delay.
- Use aria-disabled instead of disabled on a button that needs a tooltip, so it stays focusable.
- Keep tooltip text short and never put links or buttons inside it.
- Do not rely on a tooltip for instructions people need; touch users may never see it.
- Use tone="error" only for error hints, and variant="glass" over photos or colored surfaces.
