# Bubble

Bubble draws the coloured or bordered shape around message text and sizes it to its content. A ghost variant drops the surface for assistant answers and rich content like lists and code.

## Install

```bash
npx shadcn@4.18.0 add @siteplane/bubble
```

Import it from `@/siteplane/components/bubble`. The project needs Siteplane UI's one-time setup first: [installation](https://ui.siteplane.io/docs/installation/).

## When to pick it

- **vs [Message](https://uiskillbook.com/skills/siteplane-message):** Pick Message to arrange the turn around the bubble, with avatar and actions.
- **vs [Card](https://uiskillbook.com/skills/siteplane-card):** Pick Card for content blocks outside a conversation.

## Rules

- Compose `Bubble` with a `BubbleContent` that holds the text.
- Choose `variant` by sender: `muted` for the person in an AI chat, `ghost` for assistant answers, `default` or `tinted` for your own messages between people, `destructive` for failures.
- Set `align` to match the surrounding Message.
- Put links or buttons inside the bubble or in the Message footer, since the bubble itself is not interactive.
- Say what happened in the text, not through colour alone.
