# Menu

Menu lists a short set of actions behind a trigger, such as an account menu, a table row's actions or a More button. It also holds checkbox and radio items for view options. Dropdown Menu and Context Menu build on it.

## Install

```bash
npx shadcn@4.18.0 add @siteplane/menu
```

Import it from `@/siteplane/components/menu`. The project needs Siteplane UI's one-time setup first: [installation](https://ui.siteplane.io/docs/installation/).

## When to pick it

- **vs [Select](https://uiskillbook.com/skills/siteplane-select):** Pick Select instead when people choose a value that a form submits.
- **vs [Navigation Menu](https://uiskillbook.com/skills/siteplane-navigation-menu):** Pick Navigation Menu instead for site sections with panels of links.
- **vs [Dropdown Menu](https://uiskillbook.com/skills/siteplane-dropdown-menu):** Dropdown Menu is the same component under DropdownMenu-prefixed names; pick one naming per menu.
- **vs [Command](https://uiskillbook.com/skills/siteplane-command):** Pick Command instead when the list is long enough that people should search it.

## Rules

- MenuPopup includes the portal, positioner and scrolling viewport, so don't wrap it in another portal.
- Set variant="destructive" on a MenuItem that deletes or removes something.
- Use MenuCheckboxItem for independent toggles and MenuRadioGroup for one choice; neither submits with a form.
- Use MenuLinkItem for rows that navigate so they render as real links.
- A menu item that launches a dialog needs the dialog mounted outside the menu, with its open state in your code. Mounted inside, the dialog unmounts when the menu closes.
