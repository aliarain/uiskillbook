# Animated Buttons

Animated Buttons add tactile motion to marketing calls to action, carousel arrows, learn-more links and a log out control. They keep normal Button behaviour and finish instantly under reduced motion.

## Install

```bash
npx shadcn@4.18.0 add @siteplane/animated-buttons
```

Import it from `@/siteplane/components/animated-buttons`. The project needs Siteplane UI's one-time setup first: [installation](https://ui.siteplane.io/docs/installation/).

## When to pick it

- **vs [Button](https://uiskillbook.com/skills/siteplane-button):** Pick plain Button for everyday app actions where motion would distract.
- **vs [Icon Morphs](https://uiskillbook.com/skills/siteplane-icon-morphs):** Pick Icon Morphs for a menu toggle whose bars turn into a close icon.

## Rules

- Use `FillSweepButton` with `sweep` (`reverse` or `through`), `arrow` (`bare` or `tile`) and `arrowDirection` for the hover effects.
- Give arrow-only buttons an `aria-label`, since they have no visible text.
- Use `ExpandingArrowButton` for a link-style action and `ExpandingLogoutButton` for log out, where `label` doubles as the accessible name.
- Treat `entrance` (`grow`, `widen`, `fade`) as a one-time mount effect; remount to replay it.
- Make sure each action is clear without the motion, because disabled, loading and reduced-motion states do not animate.
