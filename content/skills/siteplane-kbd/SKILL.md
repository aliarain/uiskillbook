# Kbd

Use Kbd to show the shortcut for an action, in a hint sentence, a search field addon or after a button label. It only displays keys; your app implements the shortcut.

## Install

```bash
npx shadcn@4.18.0 add @siteplane/kbd
```

Import it from `@/siteplane/components/kbd`. The project needs Siteplane UI's one-time setup first: [installation](https://ui.siteplane.io/docs/installation/).

## When to pick it

- **vs [Code](https://uiskillbook.com/skills/siteplane-code):** Pick Code instead for commands, values or source snippets.
- **vs [Command](https://uiskillbook.com/skills/siteplane-command):** Use Command's own shortcut part inside a command palette.

## Rules

- Wrap keys pressed together in KbdGroup.
- Show labels that match the person's platform, such as Cmd on macOS and Ctrl elsewhere.
- Implement every shortcut you display; Kbd adds no key handling.
- Never make the shortcut the only way to find or run the action.
- Remember a Kbd after a button label becomes part of the button's accessible name.
