# Attachment

Attachment shows files in a chat composer, in a sent message or in an upload row, including progress, failures and retry. Cards can sit in a horizontally scrolling group and open a preview.

## Install

```bash
npx shadcn@4.18.0 add @siteplane/attachment
```

Import it from `@/siteplane/components/attachment`. The project needs Siteplane UI's one-time setup first: [installation](https://ui.siteplane.io/docs/installation/).

## When to pick it

- **vs [File Type Icon](https://uiskillbook.com/skills/siteplane-file-type-icon):** Use File Type Icon on its own for a simple list row without upload state or actions.
- **vs [Prompt Input](https://uiskillbook.com/skills/siteplane-prompt-input):** Inside Prompt Input, put small attachment cards in `PromptInputAttachments`.

## Rules

- Set `state` (`idle`, `uploading`, `processing`, `error`, `done`) from your upload code, and say the state in `AttachmentDescription` too.
- Give every `AttachmentAction` and `AttachmentTrigger` an `aria-label` that includes the file name.
- Use `orientation="vertical"` with `AttachmentMedia variant="image"` for image thumbnails and `size="sm"` inside fields.
- Wrap rows in `AttachmentGroup` with a `label` and stable keys, and move focus elsewhere before removing a card.
- The card uploads nothing; your app starts, retries and cancels uploads.
