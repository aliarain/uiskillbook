# Stepper

Stepper shows progress through a sequence such as onboarding or setup, and can reveal the content of the step that is open. It is a display and navigation aid; your app decides when a step is complete.

## Install

```bash
npx shadcn@4.18.0 add @siteplane/stepper
```

Import it from `@/siteplane/components/stepper`. The project needs Siteplane UI's one-time setup first: [installation](https://ui.siteplane.io/docs/installation/).

## When to pick it

- **vs [Timeline](https://uiskillbook.com/skills/siteplane-timeline):** Pick Timeline for past events in date order rather than steps someone moves through.
- **vs [Progress](https://uiskillbook.com/skills/siteplane-progress):** Pick Progress when only a percentage matters and the steps have no names.

## Rules

- Use `StepperItem` for read-only steps and `StepperButtonItem` for every step people can open, without mixing the two for the same step.
- Set `status` (`done`, `current`, `open`, `blocked`) for progress and `active` on a button item for which step is open; they are independent.
- Pass children to show content under a step; it sits outside the button, so it can hold fields and links.
- Keep or translate `statusLabel`, because done and blocked appear only as icons.
- Collapsed step content turns inert, so shift focus forward yourself once a step closes.
