# Dropdown Menu

Dropdown Menu serves code that prefers shadcn-style part names such as DropdownMenuContent. It matches Menu in behavior, styling and API; only the names differ.

## Install

```bash
npx shadcn@4.18.0 add @siteplane/dropdown-menu
```

Import it from `@/siteplane/components/dropdown-menu`. The project needs Siteplane UI's one-time setup first: [installation](https://ui.siteplane.io/docs/installation/).

## When to pick it

- **vs [Menu](https://uiskillbook.com/skills/siteplane-menu):** Pick Menu instead if the rest of your code uses Menu part names; never mix both naming sets in one menu.
- **vs [Context Menu](https://uiskillbook.com/skills/siteplane-context-menu):** Pick Context Menu instead when the same actions should open on right-click of an element.
- **vs [Select](https://uiskillbook.com/skills/siteplane-select):** Pick Select instead when the choice is a form value.

## Rules

- Use only DropdownMenu-prefixed parts inside one menu; do not mix them with Menu parts.
- Do not wrap DropdownMenuContent or DropdownMenuSubContent in another portal; they include one.
- Start action items with a fitting icon; checkbox and radio items already draw an indicator, so give them none.
- Give items that remove something variant="destructive".
- Set the same variant on DropdownMenuSubContent as on its parent, for example glass.
