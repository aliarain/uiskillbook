# Badge

Badge tags a piece of content with a short word or number, such as Draft, Paid, New or an unread count. It also covers status-with-dot text, plan entitlements and a verified mark on an avatar.

## Install

```bash
npx shadcn@4.18.0 add @siteplane/badge
```

Import it from `@/siteplane/components/badge`. The project needs Siteplane UI's one-time setup first: [installation](https://ui.siteplane.io/docs/installation/).

## When to pick it

- **vs [Tag Group](https://uiskillbook.com/skills/siteplane-tag-group):** Pick Tag Group when the labels can be selected, removed or navigated with the keyboard.
- **vs [Marker](https://uiskillbook.com/skills/siteplane-marker):** Pick Marker for a quiet status line inside a chat thread rather than a chip on a row.

## Rules

- Choose `variant` by meaning (`success`, `warning`, `error`, `info`, `accent`, `secondary` and so on) and always keep a visible word beside the colour.
- Use `profile="status"` for a coloured dot followed by the state in words, and `profile="count"` for a notification number that never truncates.
- Give a count badge a contextual accessible name with hidden text, and hide decorative icons and dots from assistive technology.
- Make a badge a link with `render`; otherwise it is a plain, non-interactive span and should not be used as a button.
- Reserve `light` for the single announcement on a page, on an opaque variant.
