# Marker

Marker covers the in-between lines of a conversation: a thinking indicator, a stopped-reply note, a model change or a Today separator. It sits as its own row between turns or inside a turn's content.

## Install

```bash
npx shadcn@4.18.0 add @siteplane/marker
```

Import it from `@/siteplane/components/marker`. The project needs Siteplane UI's one-time setup first: [installation](https://ui.siteplane.io/docs/installation/).

## When to pick it

- **vs [Message](https://uiskillbook.com/skills/siteplane-message):** Pick Message for anything a participant actually said.
- **vs [Trace](https://uiskillbook.com/skills/siteplane-trace):** Pick Trace for the list of steps an agent took, with expandable details.
- **vs [Badge](https://uiskillbook.com/skills/siteplane-badge):** Pick Badge for a chip on a row rather than a full-width thread line.

## Rules

- Compose `Marker` with an optional `MarkerIcon` and a `MarkerContent`.
- Set `role="status"` on lines that change, such as a live Thinking status, so they are announced.
- Use `variant="separator"` for dates and breaks, and `variant="border"` for a note that heads the thread.
- Put a Spinner in `MarkerIcon` for a reply in progress and hide decorative icons from assistive tech (the part does this).
- Keep important wording in the text because the marker colour is deliberately muted.
