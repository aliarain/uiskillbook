# Glass

Glass lets controls and cards float over photos, video, maps or colourful surfaces while staying legible. It is a `variant` on existing components rather than a component of its own.

## Install

```bash
npx shadcn@4.18.0 add @siteplane/button @siteplane/card @siteplane/popover @siteplane/tooltip @siteplane/menu @siteplane/context-menu @siteplane/dropdown-menu
```

The project needs Siteplane UI's one-time setup first: [installation](https://ui.siteplane.io/docs/installation/).

## When to pick it

- **vs [Card](https://uiskillbook.com/skills/siteplane-card):** Keep the default Card surface on plain pages, where glass shows almost nothing.
- **vs [Popover](https://uiskillbook.com/skills/siteplane-popover):** Set the glass tone attributes on the popup itself, since popovers render outside their trigger.

## Rules

- Set `variant="glass"` on Button, Tooltip, Popover, Menu, Context Menu, Card or `DropdownMenuContent`.
- Use it only with a picture or colour behind it; on a flat background keep the default surface.
- Switch to a lighter panel with `data-glass-tone="light"` or dark text with `data-glass-ink="dark"`, on the component or a wrapper.
- Check text contrast against your real imagery and keep long text on a solid surface.
