# Message Scroller

Message Scroller holds the turns of a chat or AI conversation, keeps a new turn in view, follows a reply as it streams and keeps position when older messages load above. It also acts as a log so screen readers hear new rows.

## Install

```bash
npx shadcn@4.18.0 add @siteplane/message-scroller
```

Import it from `@/siteplane/components/message-scroller`. The project needs Siteplane UI's one-time setup first: [installation](https://ui.siteplane.io/docs/installation/).

## When to pick it

- **vs [Message](https://uiskillbook.com/skills/siteplane-message):** Use Message inside each row to lay out a single turn.
- **vs [Marker](https://uiskillbook.com/skills/siteplane-marker):** Use Marker rows between turns for dates, notes and a thinking status.
- **vs [Prompt Input](https://uiskillbook.com/skills/siteplane-prompt-input):** Place Prompt Input below the scroller as the composer.

## Rules

- Make every row a `MessageScrollerItem` directly inside `MessageScrollerContent`, with a stable `messageId` that also serves as the React key.
- Mark the first row of each turn with `scrollAnchor`; that is normally the user's own message.
- Turn on `autoScroll` to follow a growing reply, and set `busy` on `MessageScrollerContent` while a reply is pending.
- Add `MessageScrollerButton` for the jump-to-latest control and use `useMessageScroller()` for custom jumps.
- Load long histories in pages above the first row; rows are not virtualised.
