# Icon Morphs

Icon Morphs provides the hamburger toggle for mobile and compact navigation. It owns its expanded state attribute and label, and pairs well with a Collapsible panel.

## Install

```bash
npx shadcn@4.18.0 add @siteplane/icon-morphs
```

Import it from `@/siteplane/components/icon-morphs`. The project needs Siteplane UI's one-time setup first: [installation](https://ui.siteplane.io/docs/installation/).

## When to pick it

- **vs [Toggle](https://uiskillbook.com/skills/siteplane-toggle):** Pick Toggle for an on/off control that does not open navigation.
- **vs [Theme Toggles](https://uiskillbook.com/skills/siteplane-theme-toggles):** Pick Theme Toggles for a light and dark switch.

## Rules

- Use `MenuIconMorph` with `open` and `onOpenChange`, or `defaultOpen` for local state.
- Point `aria-controls` at the navigation element it shows and hides.
- Keep the built-in open and close labels or pass your own `aria-label`.
- Feed the same `open` value to a Collapsible that holds the navigation so both move together.
- Use `onClick` with `preventDefault()` only when you must cancel the toggle.
