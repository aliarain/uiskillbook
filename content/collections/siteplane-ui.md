[Siteplane UI](https://ui.siteplane.io) is a React kit that installs as editable source through the shadcn CLI. It is the design system UI Skillbook itself is built on. This collection has one entry per component, grouped as Siteplane groups them: Actions, Forms & selection, Navigation, Overlays & disclosure, Date & color, Data display, Charts, Chat & AI, Feedback, Layout & utilities, Animated, Glass.

Set up the kit once with the [installation guide](https://ui.siteplane.io/docs/installation/), and install Siteplane's own agent skill with `npx skills@1.5.25 add https://ui.siteplane.io -a claude-code`. Each entry here adds the install command, the neighbours it is often confused with, and a link to its full docs.
