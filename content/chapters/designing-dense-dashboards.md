Dense interfaces are hard to get right because every decision — type scale, alignment, color, navigation — compounds. This chapter groups the four skills that matter most for admin panels, analytics tools, and other data-heavy screens.

Start with information density and table scannability, since those govern the bulk of the content. Then check navigation (so users don't get lost in a dense sidebar) and color contrast (so status color still means something once the page is full of numbers).
